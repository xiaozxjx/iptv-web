# 直播厅 · IPTV 网页播放器 使用说明

更新日期：2026-11-13

一个跑在本机 Windows 上的局域网 IPTV 网站。网页端用 hls.js 播放，频道由本机 `ysp-live.py` 生成（央视频，约 63 个频道）。内置便携版 Node.js 与 Python，**不需要安装任何环境、不需要联网装依赖、不需要管理员权限**。

- 本机访问：`http://127.0.0.1:8088`
- 局域网访问：`http://<运行服务的电脑 IP>:8088`（例如 `http://192.168.12.87:8088`）
- 必须用 `http://`，不要用 `https://`（浏览器会拦截 http 视频流）

---

## 一、快速开始

| 步骤 | 操作 |
|---|---|
| 1 | 把 `iptv-web.zip` 解压到一个固定目录（不要留在压缩包里双击） |
| 2 | 双击 **`start.vbs`**（完全无窗口启动，不会弹出命令行） |
| 3 | 浏览器打开 `http://127.0.0.1:8088` |

停止：双击 **`stop.vbs`**（同样无窗口）。改过 `index.html` / `server.js` / `ysp-live.py` 后必须先 `stop.vbs` 再 `start.vbs` 才生效；只改了页面内容时，浏览器按 `Ctrl+F5` 硬刷新即可。

> `start.bat` / `stop.bat` 是带控制台窗口的等价脚本，主要用于排障。双击 `.bat` 一定会闪一下窗口，想要零窗口就用 `.vbs`。

---

## 二、文件说明

| 文件 | 作用 |
|---|---|
| `start.vbs` / `start.bat` | 启动网页服务 + 本地源，隐藏窗口 |
| `stop.vbs` / `stop.bat` | 停止两个服务，隐藏窗口版为 `.vbs` |
| `server.js` | 网页服务：静态页面、频道清单反代、HLS 清单稳定化、分片转发 |
| `ysp-live.py` | 本地直播源：央视频 JCE / bkliveinfo 双协议，仅 Python 标准库 |
| `index.html` | 播放器页面 |
| `hls.min.js` | 本地化的 hls.js，不依赖 CDN |
| `channels.json` | 63 频道列表快照，本地源暂时连不上时兜底显示 |
| `runtime\node\node.exe` | 内置 Node.js v26.13.0 便携版 |
| `runtime\python\` | 内置 Python 3.15.2 embeddable 便携版 |
| `logs\` | 运行日志（随运行生成，不在分发包里） |

两个服务各占一个端口：

| 服务 | 默认端口 | 说明 |
|---|---|---|
| 网页服务 `server.js` | `8088` | 监听 `0.0.0.0`，本机与局域网都能访问 |
| 本地源 `ysp-live.py` | `20345` | 生成频道清单和分片地址 |

## 三、页面操作

### 快捷键

| 按键 | 作用 |
|---|---|
| `↑` / `↓` | 上一个 / 下一个频道 |
| `←` / `→` | 音量减 / 加 5% |
| `空格` | 播放 / 暂停（直播流一般不需要） |
| `F` | 全屏 |
| `M` | 静音切换 |
| `/` | 聚焦搜索框 |

### 顶栏按钮

| 按钮 | 作用 |
|---|---|
| 「频道」 | 在窄屏下展开 / 收起频道列表 |
| 「◐ 沉浸」 | 控制条自动隐藏开关，开启时静止 3 秒收起 |
| 「⇅ 换台」 | 反转 `↑`/`↓` 的换台方向，设置会记住 |
| 「↻ 刷新」 | 重新拉取频道列表 |

### 鼠标交互

- **点击画面**：显示控制条，再点一下关闭；直播不会因为点击而暂停。
- **鼠标移到画面下缘**：唤出控制条；静止 3 秒自动隐藏。
- **全屏时移到画面左缘**：唤出频道列表，移开自动收起。
- **控制条**：音量滑块、静音、画中画、复制当前流地址、全屏。
- **频道列表**：搜索框、全部频道 / 我的收藏分组、收藏星标。
- 底部四行说明常驻，不会随控制条一起隐藏。

声音默认开启、音量 100%。浏览器若拦截首次自动播放，会临时静音，点一下画面或按任意键即自动恢复。

## 四、频道源与自动重启

**源只有一路：本机 `ysp-live.py`（端口 20345）**。页面没有源设置入口，也不读取浏览器里保存的旧源地址；局域网访问时地址自动跟随当前网页主机名，不会指向访客设备自己。

本地源由脚本自带的**监督器**托管：

- 默认**每 3 小时自动重启**一次工作进程，避免长时间运行后上游签名 / 会话失效。
- 工作进程异常退出时，10 秒后自动拉起。
- 页面缓冲加厚，重启瞬间（约 2~4 秒清单冷启动）不打断画面；服务端按 `PROGRAM-DATE-TIME` 生成只增不减的虚拟分片序号，上游重启导致序号回退时浏览器也看不到跳号。
- 重启事件写入 `logs\restart.log`。

代价是直播延迟约 20~30 秒，属于正常现象。

## 五、日志与自检

| 文件 | 内容 |
|---|---|
| `logs\node.log` | 网页服务输出；缺失 Node/Python 时的官方下载链接 |
| `logs\start-status.txt` | 每次启动的自检结果（两个服务是否起来） |
| `logs\restart.log` | 本地源监督器的启动 / 重启记录 |
| `logs\stop.log` | 每次停止的端口与进程记录 |

所有日志行都带 `[YYYY-MM-DD HH:MM:SS]` 时间戳。本地源工作进程的输出被丢弃，**不会**生成 `ysp-live.log`。

自检命令（会显示实际使用的 node / python 路径，不启动服务）：

```bat
start.bat /check
```

健康检查接口：

| 路径 | 返回 |
|---|---|
| `/health` | JSON：`ok`、频道数、耗时、上游地址 |
| `/m3u` | 频道清单 M3U |
| `/config` | 服务端默认源配置 |
| `/hls?u=<m3u8 地址>` | 稳定化后的 HLS 清单 |
| `/seg/<key>/<sn>` | 按最新签名转发的视频分片 |

`logs\node.log` 里 `IPTV 网页已启动` 后面会跟着一行 `局域网地址: http://IP:8088`，换电脑或换网络后以这行为准。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 网页打不开 | 确认双击过 `start.vbs`；看 `logs\start-status.txt` 的 `web server check`；`8088` 被占用就设环境变量 `PORT=8089` 后重启 |
| 顶部出现「本地 IPTV 服务没连上」 | 本地源没起来，看 `logs\start-status.txt` 的 `local source check`，然后 `stop.vbs` → `start.vbs` |
| 提示 `node.exe` / Python 找不到 | 正常包内自带 `runtime\`，说明目录被解压错了或 `runtime` 缺失；`logs\node.log` 里有官方便携包下载地址，把 `node.exe` 放进 `runtime\node\`、把 Python embeddable 解压到 `runtime\python\` 即可 |
| 看了很久画面卡一下 | 先 `Ctrl+F5` 硬刷新；看 `logs\restart.log` 确认是不是重启点；前端有停滞看门狗会自动重连 |
| 只有声音、画面不动 | 同上；仍不行就 `stop.vbs` → `start.vbs` 完整重启 |
| 某几个频道完全看不了 | 走备用 CDN 的频道（CCTV-11/12/14/15/16/17、部分 4K）可能返回 403，属于上游 CDN 对本机网络的拒绝，与网页服务无关 |
| 改了页面没变化 | 浏览器缓存，`Ctrl+F5` 硬刷新 |
| 停止后服务又自己起来 | 监督器会把工作进程拉回；必须用 `stop.vbs` / `stop.bat`，不要只按端口 `taskkill` |
| `https` 页面白屏或没画面 | 必须用 `http://` 打开 |

### 局域网访问

服务默认监听 `0.0.0.0`，同一 Wi-Fi 下的手机 / 电脑直接打开 `http://<服务器 IP>:8088` 即可。若连不上：

1. 确认手机与电脑在同一网段，没有开访客网络 / AP 隔离。
2. 从 `logs\node.log` 的「局域网地址」行取当前 IP（IP 会随网络变化）。
3. 若防火墙开启，用**管理员 PowerShell** 放行两个端口：

```powershell
New-NetFirewallRule -DisplayName "IPTV 8088" -Direction Inbound -Protocol TCP -LocalPort 8088 -Action Allow -Profile Any
New-NetFirewallRule -DisplayName "IPTV 20345" -Direction Inbound -Protocol TCP -LocalPort 20345 -Action Allow -Profile Any
```

只想本机访问时，把环境变量 `HOST` 设为 `127.0.0.1`。

## 七、高级配置（环境变量）

| 变量 | 默认值 | 作用 |
|---|---|---|
| `PORT` | `8088` | 网页服务端口 |
| `YSP_PORT` | `20345` | 本地源端口 |
| `HOST` | `0.0.0.0` | 网页服务监听地址，设 `127.0.0.1` 则仅本机 |
| `M3U_SRC` | `http://127.0.0.1:20345/all.m3u` | 服务端默认源；页面已固定本地源，一般不用改 |
| `NODE_EXE` / `IPTV_NODE` | 空 | 指定 `node.exe` 完整路径，优先级高于内置运行时 |
| `PY_EXE` / `IPTV_PY` | 空 | 指定 `python.exe` 完整路径 |
| `IPTV_NOLOCAL` | 空 | 设为 `1` 跳过本地源（等价 `start.bat /nolocal`，仅供排障） |
| `YSP_RESTART_HOURS` | `3` | 自动重启周期（小时），设 `0` 关闭周期重启 |
| `YSP_RESTART_AT` | `off` | 额外叠加每天定点重启，格式 `HH:MM` 或 `HH:MM:SS`，如 `02:00`；与周期取更早到点 |

运行时查找顺序：`NODE_EXE` / `PY_EXE` → 项目内 `runtime\` → 项目根目录 → 系统安装路径 → PATH。

### 脚本参数

```bat
start.bat /check          :: 只自检，不启动
start.bat /q              :: 静默启动（兼容参数）
start.bat /nolocal        :: 不启动本地源（排障用）
stop.bat                  :: 停止两个服务，结束前 pause
stop.bat /q               :: 停止两个服务，不 pause
stop.bat 8088             :: 只停 8088 端口对应的服务
```

`ysp-live.py` 由启动器以 `<端口> --no-4k` 方式拉起，不要手动加 `--_worker`（那是监督器内部使用的工作进程标记，加了会绕过自动重启）。

## 八、已知限制

- 页面只提供本地源，没有备用源或自定义源入口。
- 直播延迟约 20~30 秒，是加厚缓冲换来的稳定性，不是卡顿。
- 视频分片由浏览器直接向央视 CDN 拉取，本机只下发清单；因此对上游 CDN 网络有依赖。
- 需要用浏览器打开网页地址，直接双击 `index.html`（`file://`）无法播放。
